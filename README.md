# LabMate · H2D 新手使用准入与操作指导

福州大学 2026 秋软件工程实践 · 啊对对队 · 第二次团队作业

首期服务创客中心的一台拓竹 H2D：先核验身份和培训资格，再做开打前检查；新手在关键检查步骤获得视觉提示，熟练用户默认少打扰。锁定仅作用于 LabMate 的使用入口。本次交付是设计文档和模拟原型。真机接入安排在开发阶段。
