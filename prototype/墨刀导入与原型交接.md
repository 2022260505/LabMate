# LabMate 墨刀导入与原型交接

交互稿入口为 [docs/index.html](../docs/index.html)。这是可独立打开的单文件原型，包含学员端和管理端；身份、摄像头、视觉提示、设备状态和记录均为模拟，不需要任何真实权限或网络请求。浏览器刷新会清空本次演示记录。

## 界面参考

参照团队提供的 VoiceRecording 项目 DesignSystem：24 px 圆角卡片、约 16 px 内边距、约 44 px 可触控操作尺寸，借鉴系统蓝操作、浅底信息层和清晰的当前步骤。打印机示意图是本原型新绘制的简图，没有使用参考项目中的图片或录音资源。

## 导入墨刀

1. 在墨刀工作台新建一个原型项目，命名“LabMate · H2D 新手使用准入”。
2. 在墨刀原型中打开“HTML 转墨刀”，上传 `docs/index.html` 或粘贴完整源代码。保留生成的 AI 组件，预览以确认动态交互可用。参见[墨刀在线 HTML 编辑器官方说明](https://modao.cc/feature/html-editor/)。
3. “HTML 转墨刀”生成的代码组件默认放在无限画布上，演示模式会显示 0/0 页。需要新建一个页面，把代码组件复制进页面后，演示模式才有内容。
4. 通过墨刀生成分享链接（链接权限开启、访问权限“所有人”），在未登录窗口确认可访问。将该链接写进仓库入口和博客；静态网页预览可保留作备用。

## 画板与转场

| 画板/状态 | 显示内容 | 关键交互 |
|---|---|---|
| 身份核验 | H2D、入口锁定、模拟核验说明 | 成功和失败均到资格页，失败可以返回重试 |
| 培训资格 | 身份结果和培训状态 | 双通过进入检查；未培训锁定并可查看学习指引 |
| 新手检查 | 设备状态、主动视觉提醒、现场复核和人工确认 | 设备空闲时开放提交；有视觉提醒时先勾选现场复核 |
| 熟练用户检查 | 设备状态、人工确认，视觉不主动出现 | 可按需打开视觉提示；必要检查与新手相同 |
| 摄像头不可用 | 不可用提示、现场复核入口 | 管理员复核为单独的模拟操作，不显示视觉通过 |
| 检查完成 | 完成记录、现场流程指引 | 可重开场景或查看管理端记录 |
| 管理端 | 会话记录列表、单条原因详情 | 从记录打开详情并返回，无设备启停按钮 |

## 演示路径

- **未培训**：左侧选择对应角色 → 核验成功 → 培训资格不符，进入按钮不可用。
- **已培训的新手**：核验成功 → 进入开打前检查 → 查看平台边缘疑点 → 勾选复核与人工确认 → 提交。
- **熟练使用者**：核验成功 → 进入检查 → 默认没有视觉提示，人工确认后提交；也可按需开启提示。
- **摄像头不可用**：核验成功 → 进入检查 → 查看“摄像头不可用”提示 → 模拟管理员现场复核 → 完成人工确认并提交。
- **状态未知**：在任一检查页面切换设备状态为“状态未知”，提交按钮保持禁用；切换为空闲后继续。

打开管理端即可看到同一浏览会话产生的通过或准入锁定记录。检查项文字仅为原型示例，仍需协会审核。
